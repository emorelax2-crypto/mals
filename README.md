# MALS — мессенджер для телефона

Мессенджер в стиле Telegram + Discord: переписка в реальном времени, аудио- и
видеозвонки прямо в приложении и подарки за звёзды, которые покупаются за деньги.

Ставится на **iPhone и Android** как обычное приложение (PWA — установка из
браузера, без App Store и Google Play) либо собирается в настоящие `.ipa` / `.apk`
через Capacitor.

```
┌──────────────┐   WebSocket    ┌──────────────┐   WebRTC (P2P)   ┌──────────────┐
│  PWA-клиент  │◄──────────────►│ Node-сервер  │◄────сигналинг───►│  PWA-клиент  │
│  (web/)      │   REST /api    │ (server/)    │                  │              │
└──────────────┘                └──────┬───────┘                  └──────────────┘
                                       │ SQLite (data/mals.db)
                                       │ Stripe Checkout + вебхуки
```

## Что внутри

**Сообщения**
- Личные чаты и группы, доставка по WebSocket без перезагрузки
- Индикатор «печатает…», статусы «в сети» / «был(а) недавно», счётчики непрочитанного
- Группировка сообщений по дням и отправителям, галочки прочтения

**Звонки**
- Аудио и видео 1:1 на WebRTC, звук и картинка идут напрямую между устройствами
- Экран входящего звонка с рингтоном и вибрацией, таймер разговора
- Микрофон, камера, переключение фронтальной/основной камеры
- Запись о каждом звонке остаётся в чате (длительность, пропущенный, отклонённый)

**Подарки за деньги** (как звёзды в Telegram)
- 14 подарков четырёх уровней: common → rare → epic → legendary
- Кошелёк со звёздами, пакеты пополнения с бонусами
- Оплата картой через **Stripe Checkout**; звёзды зачисляются вебхуком
- Подарок приходит красивой карточкой в чат и остаётся в витрине профиля
- Можно дарить анонимно и с подписью

**Приложение**
- Устанавливается на домашний экран iOS и Android, работает в полноэкранном режиме
- Service worker: оболочка открывается даже без сети
- Тёмная тема, безопасные зоны под «чёлку», без единой внешней зависимости на фронте

## Быстрый старт

```bash
npm install
npm run seed     # демо-аккаунты: alice / bob / kira, пароль 123456
npm start        # http://localhost:3000
```

Откройте два окна браузера (второе — в режиме инкогнито), войдите разными
аккаунтами и попробуйте написать друг другу и позвонить.

### Как открыть с телефона

Телефон и компьютер должны быть в одной Wi-Fi-сети:

```bash
# узнать адрес компьютера в сети
ip addr | grep "inet 192" || ipconfig getifaddr en0
# затем на телефоне открыть http://<этот-адрес>:3000
```

> **Важно про звонки.** Браузер даёт доступ к микрофону и камере только на
> `localhost` или по HTTPS. По `http://192.168.x.x` переписка работает, а звонки —
> нет. Для звонков с телефона поднимите HTTPS-туннель, например
> `npx localtunnel --port 3000` или `cloudflared tunnel --url http://localhost:3000`,
> и откройте выданный `https://…`-адрес.

### Автотесты

Сквозной тест поднимает настоящий браузер, логинит двух пользователей и проверяет
переписку, подарки, кошелёк и видеозвонок по WebRTC от начала до конца:

```bash
npm i -D playwright && npx playwright install chromium
npm run seed && npm start      # в отдельном терминале
npm test                       # 15 проверок + скриншоты в test-shots/
```

## Установка на телефон (PWA)

**iPhone (Safari):** открыть сайт → «Поделиться» ⬆️ → «На экран „Домой“».
**Android (Chrome):** открыть сайт → меню ⋮ → «Установить приложение».

Иконка появится рядом с остальными приложениями, запуск — в полный экран, без
адресной строки. Подсказка встроена в приложение: Профиль → «Установить на телефон».

## Настоящие приложения для App Store и Google Play

В проекте лежит готовый `capacitor.config.json`. Нужен Mac с Xcode (для iOS) и
Android Studio (для Android):

```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/ios @capacitor/android

# укажите адрес задеплоенного сервера в capacitor.config.json → server.url
npx cap add ios
npx cap add android
npx cap sync

npx cap open ios       # дальше сборка и выгрузка через Xcode
npx cap open android   # сборка .apk / .aab через Android Studio
```

Для звонков в нативной обёртке разрешения уже нужны в манифестах:
`NSMicrophoneUsageDescription` и `NSCameraUsageDescription` в `Info.plist`,
`RECORD_AUDIO` и `CAMERA` в `AndroidManifest.xml`.

Публикация в сторах требует аккаунтов разработчика: Apple — 99 $ в год,
Google — 25 $ единоразово, плюс модерация.

## Оплата подарков реальными деньгами

Без ключей приложение работает в **DEMO-режиме**: пополнение проходит мгновенно и
деньги не списываются — это честно подписано в интерфейсе.

Чтобы включить настоящие платежи:

1. Зарегистрируйтесь в [Stripe](https://dashboard.stripe.com/register).
2. Скопируйте `.env.example` в `.env` и заполните:
   ```
   STRIPE_SECRET_KEY=sk_live_...        # или sk_test_... для тестов
   STRIPE_WEBHOOK_SECRET=whsec_...
   PUBLIC_URL=https://ваш-домен
   CURRENCY=usd                          # валюта витрины
   ```
3. В Stripe Dashboard → Developers → Webhooks добавьте эндпоинт
   `https://ваш-домен/api/stripe/webhook` с событием `checkout.session.completed`.
4. Перезапустите сервер — в кошельке появится оплата картой.

Звёзды начисляются **только** после подтверждения вебхуком с проверенной подписью,
поэтому подделать оплату со стороны клиента нельзя. Цены пакетов задаются в
`server/db.js` → `STAR_PACKS`, каталог подарков — там же в `GIFT_CATALOG`.

## Деплой

**Docker (подойдёт для любого VPS):**
```bash
docker compose up -d --build
```

**Render** — в репозитории лежит `render.yaml`: New → Blueprint, указать репозиторий,
задать `PUBLIC_URL` и ключи Stripe. WebSocket работает без настройки.

**Любой VPS вручную:**
```bash
npm ci --omit=dev
NODE_ENV=production PORT=3000 node server/index.js
```
Дальше nginx как reverse-proxy с TLS (обязательно `proxy_set_header Upgrade`
и `Connection "upgrade"` для `/ws`).

### TURN для звонков в мобильных сетях

STUN-серверов Google хватает для Wi-Fi и большинства сетей, но у операторов
сотовой связи бывает симметричный NAT — тогда нужен TURN. Поднимите `coturn`
или возьмите managed-сервис и добавьте в `.env`:

```
TURN_URL=turn:turn.example.com:3478
TURN_USERNAME=user
TURN_CREDENTIAL=secret
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register` · `/api/auth/login` | регистрация и вход, выдаёт токен |
| GET/PATCH | `/api/me` | свой профиль |
| GET | `/api/users?q=` · `/api/users/:id` | поиск и профиль с витриной подарков |
| GET | `/api/chats` | список чатов с превью и непрочитанными |
| POST | `/api/chats/dm` · `/api/chats/group` | создать личный чат или группу |
| GET/POST | `/api/chats/:id/messages` | история и отправка |
| GET | `/api/gifts` · POST `/api/gifts/send` | каталог и отправка подарка |
| GET | `/api/wallet` · POST `/api/wallet/topup` | баланс, история, пополнение |
| POST | `/api/stripe/webhook` | подтверждение оплаты |
| WS | `/ws` | сообщения, присутствие, «печатает…», сигналинг звонков |

## Безопасность

- Пароли хранятся как `scrypt` с индивидуальной солью, сравнение — постоянное по времени
- Токены сессий — 256 бит из `crypto.randomBytes`, проверяются на каждом запросе
- Подпись вебхука Stripe проверяется HMAC-SHA256 с защитой от повторов по времени
- Списание звёзд и выдача подарка выполняются одной транзакцией SQLite
- Весь пользовательский текст экранируется перед вставкой в DOM

Перед публичным запуском: смените `SESSION_SECRET`, включите HTTPS, добавьте
ограничение частоты запросов на `/api/auth/*` и регулярные бэкапы `data/mals.db`.
